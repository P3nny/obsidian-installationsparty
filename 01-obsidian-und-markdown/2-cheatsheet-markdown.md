# Markdown Cheatsheet

Reine Referenz zum Nachschlagen — keine Übung. Die wichtigsten Grundlagen reichen für 95 % dessen, was du im Alltag brauchst.

| Was | Syntax | Ergebnis |
|---|---|---|
| Überschrift 1 | `# Text` | größte Überschrift |
| Überschrift 2 | `## Text` | zweitgrößte Überschrift |
| Fett | `**Text**` | **Text** |
| Kursiv | `*Text*` | *Text* |
| Liste (ungeordnet) | `- Punkt` | • Punkt |
| Liste (geordnet) | `1. Punkt` | 1. Punkt |
| Link | `[Beschriftung](URL)` | anklickbarer Link |
| Interner Link (Obsidian) | `[[Notizname]]` | Link zu anderer Notiz |
| Code (inline) | `` `Code` `` | `Code` |
| Codeblock | ```` ```Code``` ```` | abgesetzter Codeblock |
| Zitat | `> Text` | eingerückter Zitatblock |
| Checkbox | `- [ ] Aufgabe` | ☐ Aufgabe |
| Tabelle | `\| A \| B \|` + Trennzeile `\|---\|---\|` | Tabelle mit Spalten |
