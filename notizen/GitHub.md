Ein Dienst im Netz, bei dem [[Git]]-[[Repository|Repositories]] gespeichert werden — der bekannteste von mehreren (Alternativen: GitLab, Codeberg, Bitbucket).

Wichtige Unterscheidung: **Git ist das Programm auf deinem Rechner, GitHub ist der Ort im Netz.** Du kannst Git vollständig ohne GitHub nutzen; GitHub ohne Git ergibt dagegen wenig Sinn. Die Ähnlichkeit der Namen verwirrt Einsteigerinnen zuverlässig.

Wozu der Umweg über einen Dienst? Drei Dinge, die lokal nicht gehen:

- **Backup** außerhalb deines Laptops
- **Sync** zwischen mehreren Geräten
- **Zusammenarbeit** mit anderen — inklusive öffentlichem Teilen, so wie dieses Workshop-Material selbst

Ein kostenloses Konto reicht für alles davon aus, auch für private Repositories, die niemand außer dir sieht.

*Beim Hochladen (`push`) fragt GitHub nach einer Anmeldung — und akzeptiert dafür seit 2021 kein Konto-Passwort mehr. Wie es stattdessen geht, steht im Bonus-Kapitel Git.*
