Eine Auszeichnungssprache, mit der du Text formatierst, indem du Zeichen mittippst statt Knöpfe zu drücken. `**fett**` wird zu **fett**, `# Überschrift` wird zur Überschrift.

Der Clou: Eine Markdown-Datei bleibt eine ganz normale Textdatei. Du kannst sie in jedem Editor öffnen, und selbst unformatiert ist sie gut lesbar — anders als eine Word-Datei, die ohne Word nur wirrer Zeichensalat ist. Genau deshalb ist Markdown die Grundlage für einen [[Vault]], der Jahrzehnte überdauern soll.

| Du tippst        | Ergebnis                |
| ---------------- | ----------------------- |
| `# Text`         | Große Überschrift       |
| `**Text**`       | **fett**                |
| `*Text*`         | *kursiv*                |
| `- Text`         | Aufzählungspunkt        |
| `[[Notizname]]`  | Link zu einer Notiz     |
| `` `Text` ``     | `Code`                  |

Erfunden 2004 von John Gruber, heute überall zu finden: GitHub, Reddit, Discord, Notion, WhatsApp (in Teilen) — und eben [[Obsidian]]. Das [[Frontmatter]] am Anfang dieser Notiz ist eine verbreitete Erweiterung davon.
